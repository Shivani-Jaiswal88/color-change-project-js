# 🎨 Color Change Project

A simple and interactive **Color Change Project** built using **HTML, CSS, and JavaScript**.

The goal of this project is simple: **click a color button to change the background color of the page.**

For example, clicking the **Red** button changes the background color to red, while clicking the **Green** button changes it to green.

This project was created as a practice project to improve my understanding of **HTML, CSS, JavaScript, DOM manipulation, and events**.

## ✨ Features

* 🔴 Click the Red button to change the background to red
* 🟢 Click the Green button to change the background to green
* 🔵 Click the Blue button to change the background to blue
* 🖱️ Interactive color buttons
* ⚡ JavaScript event handling
* 🎨 Dynamic background color changes
* 🌐 Simple and clean UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

This project was created for **HTML, CSS, and JavaScript practice**, especially to understand:

* DOM manipulation
* Event handling
* Click events
* Changing CSS styles using JavaScript
* Using `data-*` attributes
* Working with variables and functions
